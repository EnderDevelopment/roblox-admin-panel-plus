# Redemption Admin Panel

This project contains a Roblox script for an admin panel with commands for kick, ban, give, announce, and teleport players. The panel includes a central theme of redemption and sound effects for opening the panel and background music. The script is designed to be placed in the ServerScriptService of a Roblox game and includes customizable admin check logic, sound effects, and redemption theme features.

## Install

1. Place the `RedemptionAdminPanel.lua` script in the `ServerScriptService` of your Roblox game.
2. Customize the admin check logic in the `isAdmin` function to match your game's admin system.
3. Replace the placeholder sound IDs with actual sound IDs from Roblox's audio library.
4. Customize the redemption logic in the `handleRedemption` function to fit your game's redemption theme.

## Use

1. Run the Roblox game.
2. Admins will see the Redemption Admin Panel GUI when they join the game.
3. Use the buttons in the admin panel to perform various commands:
   - Kick Player: Kicks a specified player from the game.
   - Ban Player: Bans a specified player from the game.
   - Give Item: Gives a specified item to a player.
   - Announce: Makes an announcement to all players.
   - Teleport Player: Teleports a player to a specified location.
4. The admin panel includes sound effects for opening the panel and background music while the panel is open.
5. Customize the redemption theme features to fit your game's requirements.
